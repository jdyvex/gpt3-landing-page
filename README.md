# GPT-3 Landing Page

Welcome to the GPT-3 Landing Page project! This repository contains the code for a mock landing page for the GPT-3 model. The page serves as a mock website design, created purely to demonstrate web design and frontend development skills. The page does not contain any legitimate information about GPT-3 and is not affiliated with OpenAI in any way. It’s intended solely as a portfolio project to showcase visual design, responsive layout, and frontend skills.
